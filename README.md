# AI 에이전트로 다시 설계하는 빅데이터 활용

「2026 AI·빅데이터 인사이트 컨퍼런스」(2026-11-06) AGENDA 02 발표 슬라이드입니다. 발표자: 황민호

- 슬라이드 보기: https://revfactory.github.io/ai-bigdata/
- PDF: [slides.pdf](slides.pdf)

## 조작

| 동작 | 키 |
| --- | --- |
| 다음 장 | `→`, `↓`, `Space`, `PageDown`, `Enter`, 마우스 왼쪽 클릭 |
| 이전 장 | `←`, `↑`, `PageUp`, `Backspace`, 마우스 오른쪽 클릭 |
| 처음 장 / 마지막 장 | `Home` / `End` |
| N번 장으로 이동 | 숫자 입력 후 `Enter` |
| 전체 화면 | `F` |
| 화면 가리기 | `B` |

주소 끝에 `?p=12`를 붙이면 12번 장에서 시작합니다.

## 구성

- `reel/`: HTML 슬라이드(50장)와 글꼴
- `assets/img/`: 표지·마지막 장 로고
- `slides.pdf`: 완성 화면을 모은 PDF

글꼴은 Pretendard, JetBrains Mono, Paperlogy를 사용합니다.
